# Data Sources

The datasets in this repository are derived from the following sources:
- **NASA Exoplanet Archive**: Orbital parameters for TRAPPIST-1b-g, Kepler-223b-e, Kepler-20b-f (accessed August 2025).
- **JPL Horizons**: Solar System ephemerides for Mercury, Venus, Saturn.
- **NICER**: Pulsar timing data for PSR B1913+16 and PSR J0437-4715.
- **LIGO**: Gravitational wave constraints for binary systems.
- **EHT**: Orbital constraints for M87* and Sgr A* (approximated for test particles).
- **Synthetic Data**: Gaussian noise (SD 0.5%) added to mimic observational errors, as described in Section 3 of the thesis.
