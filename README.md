# Unified Wave-Based Theory of Gravity

## Overview
This repository supports the thesis *A Unified Wave-Based Theory of Gravity: Atomic and Photon Interactions in a Scalar-Tensor Field Medium* by Alexander C. Blainey (August 18, 2025). The theory proposes gravity arises from spiral waves generated by rotating particles (atoms, photons with $m_\gamma \approx 10^{-55}$ kg) in a scalar-tensor field. It unifies quantum and cosmological scales, reproducing Newtonian gravity locally ($F \approx G m_2 M / r^2$), explaining double-slit interference via microgravity waves, and yielding a cosmological repulsive force ($F_s = k_r m_2 r$, $k_r \approx 5.2 \times 10^{-36}$ s$^{-2}$) that eliminates dark energy.

### Key Results
- **Cosmology**: $H_0 \approx 70.2$ km/s/Mpc, $\Lambda \approx 1.73 \times 10^{-52}$ m$^{-2}$, reconciling Planck and SH0ES measurements.
- **Double-Slit**: Material-dependent fringe spacing ($\Delta x \approx 0.50–0.52$ mm) challenges QED.
- **Orbital Predictions**: MAPE 0.8% (SD 0.5%) across 9 systems, outperforming GR (2.3–3.6%) and MOND (1.5–2.0%).
- **Force Tests**: Mean error 1.3% (SD 1.8%) for 35 objects.

## Repository Contents
- **/data/**:
  - `orbital_data.csv`: Orbital parameters for 9 systems (Mercury, Venus, Saturn, TRAPPIST-1b-g, Kepler-223b-e, Kepler-20b-f, PSR B1913+16, two EHT black holes).
  - `force_tests.csv`: Force data for 35 objects (alloys, planets, pulsars, black holes).

## Reproducibility
1. Install Python 3.x with `numpy`, `matplotlib`, `scipy` (`pip install numpy matplotlib scipy pandas`).
2. Run `double_slit.py` to generate interference patterns (outputs `double_slit_interference.png`).
3. Run `parameter_optimization.py` to fit model parameters.
4. Run `statistical_analysis.py` to compute MAPE and t-tests (Table 4).
5. Verify cosmological parameters ($H_0$, $\Lambda$) using equations in Section 6.

## Experimental Validation
- **Photon Mass**: Test $m_\gamma \approx 10^{-55}$ kg via pulsar timing.
- **Scalar Coupling**: Mach-Zehnder interferometer (phase shift $10^{-6}$ rad).
- **Double-Slit**: Single-photon setup to test material-dependent $\Delta x$.

## Limitations
- Double-slit material dependence needs experimental confirmation.
- Saturn anomaly (7.7% error) requires spectroscopy to align with Cassini residuals.
- Photon mass tests must distinguish from magnetic field effects.
